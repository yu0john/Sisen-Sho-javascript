# 四川省（ニコニコ ゲームアツマール再現）
ニコニコによるサービス終了で遊べなくなったゲーム四川省をJavascriptで再現するプロジェクトです。
- 有志による非公式の制作です。
- 原作者や権利者の申し立て等、何かあればこのリポジトリは直ちに削除します。
